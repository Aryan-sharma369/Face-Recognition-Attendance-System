# Face Recognition Attendance System

An AI-powered Face Recognition Attendance System built using Python, Flask, OpenCV, and the face_recognition library.

## Features

- Real-time face detection
- Face recognition using webcam
- Automatic attendance marking
- Attendance records saved in CSV
- Database integration
- Simple web interface

## Tech Stack

- Python
- Flask
- OpenCV
- face_recognition
- SQLite
- HTML
- CSS

## Installation

```bash
pip install -r requirements.txt
python main.py
```
